# Учебные графы из двух учебников

`hw2/` содержит исходные эксперименты с GraphRAG. Для HW3 используйте **один** ноутбук [`hw3/HW3_pipeline.ipynb`](hw3/HW3_pipeline.ipynb): он строит два общих графа по двум Markdown-документам после MinerU — до и после предобработки — и рассчитывает доступные метрики. Этапы, зависимости, ограничения и инструкция запуска описаны в [`hw3/README.md`](hw3/README.md).

В репозитории есть оба входа в [`hw3/input/`](hw3/input/), шаблон GraphRAG [`hw3/settings.template.yaml`](hw3/settings.template.yaml), промпты, определения моделей Ollama, код предобработки и зафиксированные зависимости. После полного запуска результаты сохраняются в [`hw3/graphs/`](hw3/graphs/) и `hw3/metrics.json`; рабочий кэш остаётся в исключённой из Git папке `local_runs/`.

Для изучения текущего запуска доступны [блоки и результаты предобработки](hw3/prepared/README.md) и [таблицы обоих графов](hw3/graphs/README.md). Они позволяют разобрать чанкинг и происхождение вершин и связей без повторного вызова моделей.
