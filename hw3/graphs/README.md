# Графы HW3

Здесь находятся четыре файла полного запуска [`HW3_pipeline.ipynb`](../HW3_pipeline.ipynb): `before.graphml`, `before.html`, `after.graphml`, `after.html`. Каждый содержит **один общий граф по двум документам**. Графы прежнего запуска по одному учебнику удалены, чтобы не смешивать результаты разных экспериментов.

GraphML хранит данные для дальнейшей обработки, HTML — интерактивный просмотр. После запуска добавьте эти файлы в Git вместе с `../metrics.json`.

## Таблицы для разбора графа

В `data/before/` и `data/after/` сохранены:

- `documents.parquet` — оба документа и список их блоков;
- `text_units.parquet` — фактические блоки GraphRAG с текстом, числом токенов, документом, идентификаторами сущностей и отношений;
- `entities.parquet`, `relationships.parquet` — исходные результаты GraphRAG с описаниями, цитатами и `text_unit_ids`;
- `communities.parquet` — сообщества графа;
- `normalized_entities.parquet`, `normalized_relationships.parquet` — таблицы после нормализации имён; именно им соответствуют опубликованные GraphML и графовые метрики;
- `normalization_audit.csv` — исходные названия и типы, итоговые названия и типы, причины пометок для проверки.

Таблицы читаются через `pandas.read_parquet`; зависимости уже зафиксированы в проекте. Исходные таблицы позволяют изучать результат модели до объединения названий, нормализованные — опубликованный граф. Связь блоков второго графа с `chunks.jsonl` описана в [`../prepared/README.md`](../prepared/README.md).
