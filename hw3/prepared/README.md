# Предобработка завершённого запуска HW3

Здесь сохранены результаты предобработки обоих учебников из запуска `hw3_pair_15da3303dce3`. Можно изучать блоки и их связь с готовым графом без Ollama и повторного построения. Это данные варианта **после предобработки**; исходные блоки варианта **до** лежат в `../graphs/data/before/text_units.parquet`.

## Файлы каждого учебника

| Файл | Для чего нужен |
|---|---|
| `chunks.jsonl` | Текст каждого блока, `id`, раздел, число токенов, тип и идентификаторы исходных частей `atom_ids`. |
| `cleaned.md` | Очищенный текст, собранный из этих блоков. Исходный Markdown для сравнения находится в `../input/`. |
| `tokens.jsonl` | Тип, текст, лемма, номер предложения и координаты токена `start`/`end` внутри блока `chunk_id`. |
| `protected.jsonl` | Оригинальный текст и координаты защищённых формул, таблиц, единиц и марок; координаты относятся к исходному Markdown. |
| `table_cells.jsonl` | Строки, ячейки, объединения ячеек и токены HTML-таблиц. |
| `review_flags.jsonl` | Места, требующие ручной проверки, включая слишком большие таблицы и неоднозначные артефакты. |
| `report.json` | Параметры, счётчики преобразований, контрольная сумма исходного текста и проверки целостности. |

В обзоре по ванадию нет HTML-таблиц и сформированных пометок для проверки; соответствующие JSONL-файлы пусты. Размер блока измерен `tiktoken/o200k_base`, а слова и символьные координаты в `tokens.jsonl` получены через `razdel`; это разные виды токенизации.

## Как найти блок в графе

`graph_mapping.jsonl` связывает каждую пару `document` + `chunk_id` с `text_unit_id` второго графа. `chunk_id` повторяется между учебниками, поэтому используйте оба поля. В графовых таблицах поле `text_unit_ids` указывает, из каких блоков получены вершина или связь.

Пример из корня репозитория:

```python
import pandas as pd

mapping = pd.read_json("hw3/prepared/graph_mapping.jsonl", lines=True)
chunks = pd.read_json("hw3/prepared/ganoshenko/chunks.jsonl", lines=True)
ganoshenko = mapping[mapping["document"] == "ganoshenko.md"]
blocks = chunks.merge(ganoshenko, left_on="id", right_on="chunk_id")

relations = pd.read_parquet("hw3/graphs/data/after/normalized_relationships.parquet")
relations_by_block = relations.explode("text_unit_ids").merge(
    mapping, left_on="text_unit_ids", right_on="text_unit_id"
)
```

Исходные ответы извлечения уже могли быть обрезаны: это отражено в `../metrics.json`. Совпадение текста цитаты не подтверждает смысловую корректность связи. Для ручного разбора полезны исходный блок, описание связи и аудит названий.

`run_info.json` фиксирует вариант пайплайна, учебники и пути к сохранённым данным относительно корня репозитория. `source_sha256` рассчитан по `read_text(encoding="utf-8").encode("utf-8")`; `cleaned_sha256` — по байтам очищенного файла исходного запуска. Поля `source` в отдельных отчётах сохраняют путь компьютера, где выполнялся расчёт, и служат сведениями о происхождении файла.

При следующем выполнении основного ноутбука этот набор обновляется автоматически вместе с графами и метриками.
